# Homebrew tap for Apix

[Apix](https://github.com/11R5/Apix) is a fast, native API client with a
command line. This tap installs the macOS app (Apple silicon and Intel) and
puts `apix` on the PATH:

```sh
brew install --cask 11r5/apix/apix
```

`Casks/apix.rb` is the cask attached to each Apix release (`apix.rb`), made by
`scripts/channel-manifests.sh` in the Apix repository; send issues there.
